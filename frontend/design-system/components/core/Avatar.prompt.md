Circular avatar showing a photo, or initials derived from `name`.

```jsx
<Avatar name="Sarnai Bat" />
<Avatar name="Bold-Erdene" tone="brand" size="lg" />
<Avatar src="/photo.jpg" name="Temuulen" />
```

Default `ink` fill with white initials matches the creator top bar. Sizes `sm`/`md`/`lg` or a number of px.
