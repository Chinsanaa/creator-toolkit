# Earnio Marketing Website UI Kit

Single-page landing site for Earnio — the Mongolian creator monetization platform.

## Files
- `index.html` — loads React + Babel from CDN, mounts site-landing.jsx
- `site-landing.jsx` — full interactive landing page

## Sections
1. Glass sticky nav (logo, links, audience toggle, CTA)
2. Hero — dynamic earnings card visual with bar chart + floating chips
3. How it works — 4-step carousel
4. Features — 4 benefits grid
5. Testimonials — 3-card grid
6. FAQ — accordion with expand animation
7. Dark CTA band
8. Footer

## Usage
Open `index.html` in a browser. No build step needed.
