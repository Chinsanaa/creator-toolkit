Status pill / label for application states, platform tags and counts.

```jsx
<Badge tone="success" dot>Approved</Badge>
<Badge tone="warning" dot>Pending</Badge>
<Badge tone="brand">Featured</Badge>
<Badge tone="neutral">TikTok</Badge>
```

Tones: `neutral | brand | success | warning | danger | solid | outline`. Set `dot` for live-status badges.
