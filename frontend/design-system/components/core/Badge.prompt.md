A pill badge for status, category, and eyebrow labels.

```jsx
<Badge tone="success" dot>Approved</Badge>
<Badge tone="warning">Pending review</Badge>
<Badge tone="primary" eyebrow>Creator dashboard</Badge>
```

Tones: `neutral`, `primary`, `accent`, `success`, `warning`, `danger`. Use `eyebrow` for the uppercase tracked label that sits above section/page titles; `dot` adds a leading status dot for application/transaction states.
