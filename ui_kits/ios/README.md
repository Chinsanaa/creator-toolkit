# Earnio iOS App UI Kit

Full iPhone app flow inside an iPhone 26 Liquid Glass frame (402×874).

## Files
- `index.html` — mounts ios-app.jsx
- `ios-frame.jsx` — iPhone frame component
- `ios-app.jsx` — full app state machine

## Screens
- Onboarding — 3-slide carousel with dot indicators
- Signup / Login — full-screen form with success state
- Home — greeting, stat cards, platform sync status
- Explore — search + sponsorship cards with apply state
- Wallet — balance card, payout form, transaction list
- Profile — avatar, settings list, logout
