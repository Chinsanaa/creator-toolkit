# Earnio Creator App UI Kit

Full desktop creator dashboard — glass sidebar + topbar shell with three screens.

## Files
- `index.html` — mounts creator-app.jsx
- `creator-app.jsx` — complete dashboard shell

## Screens
- Dashboard — 4 stat cards, 12-month bar chart, platform breakdown, recent earnings list
- Explore — search + platform filter tabs, 3×3 sponsorship card grid with apply state
- Wallet — stat cards, request-payout form, bank accounts, transaction history table
